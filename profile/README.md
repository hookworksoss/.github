### About Us

HookWorks OSS is the open-source engineering wing of [HookWorks](https://hookworkshq.com). We design and maintain modular, production-ready tools, libraries, and developer utilities designed to eliminate boilerplate and simplify engineering workflows.

### Contributing

We welcome contributions from engineers and developers worldwide. Whether fixing bugs, submitting feature requests, or improving documentation:

1. **Pick an issue:** Check open issues with the [`good first issue`](https://github.com/search?q=org%3Ahookworksoss+is%3Aissue+label%3A%22good+first+issue%22) tag.
2. **Follow guidelines:** Review our project-level `CONTRIBUTING.md` and Code of Conduct before opening a pull request.
3. **Open an RFC:** Propose larger architectural changes by starting an issue or discussion first.
